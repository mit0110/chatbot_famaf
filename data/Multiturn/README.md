# 📄 README — Diferencias entre las 3 versiones

### **Versión 1**

- Conversaciones con **mucha dependencia entre turnos**.
- Las preguntas se encadenan fuertemente y requieren recordar lo anterior.
- Refleja lo que pediste primero: *evaluar memoria conversacional y resolución contextual fuerte*.

### **Versión 2**

- Conversaciones con **dependencia moderada**, lenguaje más natural.
- Evita tecnicismos y sigue los temas del FAQ original.
- Responde a tu pedido de hacerlo “más natural estilo alumno” sin agregar información nueva.

### **Versión 3**

- Conversaciones con **mínima dependencia entre turnos**.
- Cada pregunta puede mapearse al FAQ sin necesitar mucho contexto previo.
- Diseñada específicamente según tu pedido final: *optimizada para un agente que solo reformula y busca en embeddings*.
